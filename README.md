# Quotation

加工成本與報價工具｜繁體中文・個人試算版

輸入每月支出，換算全廠平均機台與直接人工費率，再依訂單數量、機台占用時間、人工投入與材料外包費計算建議售價。

## 第一次使用

1. 用固定的 HTTP(S) 網址開啟此工具。GitHub 的程式碼頁面不是工具操作頁面；需另行部署靜態網站，或按下方方法在本機啟動。
2. 按「載入示範」先試算。範例全部是假資料：100 件的單件成本為 69.40 元、20% 估算毛利下建議單價為 86.75 元。
3. 到「成本設定」改成自己的月支出與有效工時，按「儲存基本成本」。
4. 回到「訂單試算」，按「套用最新成本」，填寫訂單後「儲存為新報價」。
5. 定期按「匯出完整備份」，妥善保存下載的 JSON。換電腦時在「報價紀錄」匯入；確認後會整批取代該瀏覽器資料。

**修改基本成本不會改寫歷史報價。** 載入舊報價使用當時的成本快照；只有點「套用最新成本」才會變更草稿，再按「更新這筆報價」保存。

## 在電腦啟動（需要 Python 3）

解壓後，在包含 `index.html` 的資料夾開啟終端機：

```bash
python -m http.server 8080 --bind 127.0.0.1
```

若電腦的指令是 `python3`，使用 `python3 -m http.server 8080 --bind 127.0.0.1`。
瀏覽器開啟 `http://localhost:8080`；結束時在終端機按 Ctrl+C。

不要直接雙擊 index.html：ES modules 需透過 HTTP(S) 載入。請固定用同一網址與埠號；`localhost` 與 `127.0.0.1` 視為不同資料來源。

## 如何放進你的 GitHub 倉庫

目標：`jasonwu-093026/Quotation`。

1. 先把 ZIP 解壓。
2. 在 GitHub 倉庫的分支選單建立 `feat/quotation-v1` 分支。
3. 選「Add file → Upload files」。將解壓後 **quotation-v1 資料夾裡面的檔案與資料夾** 上傳，讓 `index.html` 直接位於倉庫根目錄，不要只上傳 ZIP，也不要多包一層資料夾。
4. 提交說明可填 `Add quotation calculator v1`，確認提交至新分支。
5. 建立 Pull Request，比對修改後再合併。既有 `.github/ISSUE_TEMPLATE` 不需刪除或重建。
6. 這一步只是保存程式。網站部署另行處理；尚未自動部署或推送此開發副本。

## 計算口徑

- 全廠有效機台分鐘 = 台數 × 月工作天數 × 每日機台小時 × 60 × 機台有效使用率。
- 機台費率 =（折舊 + 維修 + 分配房租 + 分配電費 + 共用耗材）÷ 全廠有效機台分鐘。不含直接人工。
- 有效人工人分鐘 = 人數 × 月工作天數 × 每日人工小時 × 60 × 人工有效投入率。
- 人工費率 = 直接人工月總成本 ÷ 有效人工人分鐘。
- 整批成本 = 件數 ×（每件機台分鐘 × 機台費率 + 每件人工人分鐘 × 人工費率 + 每件材料 + 每件外包）+ 整批架機機台費 + 整批架機人工費 + 整批專用刀具。
- 單件成本 = 整批成本 ÷ 件數。
- 建議售價 = 單件成本 ÷（1 − 目標估算毛利率），向上取至 0.01 元。整批金額用取整後單價乘件數。

機台時間為所有工序占用機台時間的總和；人工為所有人員實際投入人分鐘的總和。一人看多機不代表再將人工費率除以機台數。有效率已在費率分母中計算，不需再除一次。

直接人工總成本應與投入工時一致；可包含薪資、加班、雇主負擔及獎金分攤。月耗材不要重複計入訂單專用刀具，空壓電費不要重複計入電費及耗材。

未輸入的管理、運费、稅、融資等不會自動計入。第一版沒有自動良率或重工模型，使用者需在費用及時間中估入、於備註說明。估算毛利不等同財務報表毛利或公司淨利。

## 資料保存

- 只用瀏覽器 localStorage；沒有帳號、雲端同步或伺服器資料庫。
- 不將輸入的成本與報價傳回 GitHub，不使用追蹤程式或第三方字型。
- 不同電腦、瀏覽器、網站網址或連接埠，各自有不同紀錄。清除瀏覽器網站資料會移除本機紀錄。
- 備份為明文 JSON，包含基本成本、報價及成本快照，請保管好，不要提交到公開倉庫。
- 匯出會包含目前**有效**的未保存草稿與有效基本成本輸入。無效輸入需先修正。
- 匯入只接受本工具 schemaVersion 1、calculationVersion 1 的完整備份，最大 10 MB；未知格式拒絕且不改原資料。
- 若儲存失敗，畫面會顯示「尚未保存」，資料仍留在目前分頁，請立即匯出。讀取異常時不覆寫原本資料，可下載原始內容或匯入有效備份。
- 其他分頁改動紀錄時，本頁停止覆寫；先匯出草稿，再重新整理。

## 測試與驗算

核心測試無第三方套件，需要 Node.js 22 或更新版本：

```bash
npm test
```

瀏覽器操作驗證使用 Playwright（開發用途，非產品依賴），先啟動上述 HTTP 服務，再執行：

```bash
npm install --no-save playwright
npx playwright install chromium
node tests/browser-smoke.cjs
```

測試預設網址為 `http://127.0.0.1:8080`。可用 `QUOTATION_TEST_URL` 指定測試網址、`QUOTATION_CHROMIUM_PATH` 指定已安裝 Chromium。測試使用隔離瀏覽器環境與假資料。

驗收結果見 [docs/acceptance.md](docs/acceptance.md)。

## 檔案說明

- `index.html` / `styles.css`：畫面及手機版排版。
- `src/app.js`：使用者操作與畫面狀態。
- `src/calculator.js` / `src/decimal.js`：成本公式與精確十進位計算。
- `src/validation.js`：欄位與備份格式驗證。
- `src/storage.js`：本機保存及匯入匯出。
- `src/quotes.js`：報價紀錄與成本快照。
- `tests/`：手算案例、資料保存、快照與瀏覽器操作驗證。
- `docs/superpowers/`：已確認的設計規格及實作計畫。

後續多人填報、共用資料庫與權限另行規劃，第一版不包含這些功能。
